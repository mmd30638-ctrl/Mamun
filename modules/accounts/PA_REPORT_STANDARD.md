# পার্টনার অ্যাকাউন্টিং — রিপোর্ট ইন্টারন্যাশনাল স্ট্যান্ডার্ড (PA-INTL-100)

## ১০.৯৮.৯৮২+ — যাচাই তালিকা

| নীতি | বাস্তবায়ন |
|------|-----------|
| রিপোর্টের সব টাকা সার্ভার থেকে | `pa_period_totals()`, `pa_share_cuts()`, `pa_opening()` — GET শুধু তারিখ |
| তারিখ শুধু এক মাসের ভিতর | `pa_resolve_report_range()` — `rf`/`rt` ক্ল্যাম্প |
| মাস বন্ধ/লক, মূলধন, ব্যালেন্স এডিট | শুধু `month=` + POST + CSRF (`actions/partner_accounting.php`) |
| রেঞ্জ পেজ শুধু পড়া | কোনো hidden amount ফিল্ড নেই রিপোর্ট সেকশনে |
| অডিট | `pa_audit()` সংরক্ষণ অ্যাকশনে |
| অ্যাডমিন গার্ড | `pa_guard()` |

## ব্যবহারকারী প্রবাহ

1. হিসাব মাস বেছে নিন (লক ও বইয়ের মাস)।
2. শুরু–শেষ তারিখ (১–৩০) সেট করুন।
3. **রিপোর্ট দেখুন** — KPI, পার্টনার টেবিল, বিক্রয়/খরচ/ক্রয় এক রেঞ্জে।
4. **স্টেটমেন্ট তৈরি ও শেয়ার** (`partner_sales_share.php`) — ক্রম: বিক্রয় (প্রতি লাইনে পার্টনার অংশ) → খরচ (পার্টনার কাটা) → ক্রয় → শেষ পাতায় ৬-কলাম সারাংশ (সাবেক · +লাভ · −খরচ · নিট · মাস শেষ) + প্লাস/মাইনাস বিবরণ। এক মাসে `pa_statement_period_summary()` = ড্যাশবোর্ড সময়কাল টেবিল।

**মানদণ্ড ঘোষণা:** এই পেজের রিপোর্ট লেয়ার **PA-INTL-100** — পড়ার UI পরিবর্তনে অ্যামাউন্ট বদলায় না; শুধু সার্ভার-সাইড POST অ্যাকশন ব্যালেন্স/লেনদেন বদলায়।

**লাভ → ব্যালেন্স (১০.৯৮.৯৮৩+):** «ক্যাটাগরি ও নিট লাভ» টেবিলে পরিশোধ/লাভ বণ্টন বাটন নেই। নিট অংশ `pa_partner_book()` লেজারে স্বয়ংক্রিয়। উত্তোলন শুধু **উত্তোলন** ট্যাবে (`capital_withdrawal`) — ব্যালেন্স কমে।
