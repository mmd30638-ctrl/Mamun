# ফার্মেসি

আপনশপের লাইভ সাইটের ওপর এই প্রজেক্ট বসাবেন না। নতুন ফোল্ডার বা নতুন সাবডোমেইনে দিন। টেবিলের নাম `pharm_` দিয়ে শুরু।

## চালানো

1. জিপ খুললে `Pharmacy_Management_System` ফোল্ডার পাবেন।
2. হোস্টিংয়ে নতুন ডাটাবেজ বানান। আপনশপের ডাটাবেজ ব্যবহার করবেন না।
3. `.env.example` কপি করে `.env` করুন এবং ডাটাবেজের তথ্য দিন।
4. সাইট খুলে ইনস্টল করুন। অ্যাডমিন পাসওয়ার্ড অন্তত ৮ অক্ষর। ইউজারনেম `admin`।
5. সেটিংস থেকে পাসওয়ার্ড বদলান।

ওষুধের ব্যাচ, উৎপাদন ও মেয়াদ, পিস/স্ট্রিপ/বক্স, ক্রয়-বিক্রয়, মেয়াদোত্তীর্ণ বাতিল, ডাক্তার ও প্রেসক্রিপশন, বকেয়া, ক্যাশ ও মেমো একসাথে চলে। বিক্রয়ে আগে মেয়াদ কাছের ব্যাচ কাটে।
