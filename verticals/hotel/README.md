# হোটেল ও রেস্টুরেন্ট

আপনশপের লাইভ সাইটের ওপর এই প্রজেক্ট বসাবেন না। নতুন ফোল্ডার বা নতুন সাবডোমেইনে দিন। টেবিলের নাম `hms_` দিয়ে শুরু, তাই আপনশপের টেবিলের সাথে মেশে না।

## চালানো

1. জিপ খুললে `Hotel_Management_System` ফোল্ডার পাবেন।
2. হোস্টিংয়ে নতুন ডাটাবেজ বানান। আপনশপের ডাটাবেজ ব্যবহার করবেন না।
3. `.env.example` কপি করে `.env` করুন এবং ডাটাবেজের নাম, ইউজার, পাসওয়ার্ড লিখুন।
4. ব্রাউজারে সাইট খুললে ইনস্টল পাতা আসবে। অ্যাডমিন পাসওয়ার্ড অন্তত ৮ অক্ষর দিন।
5. ইউজারনেম `admin`। সেটিংস থেকে পাসওয়ার্ড বদলান।

ভাষা বদলাতে উপরে **English** বা **বাংলা** চাপুন।

রুম, বুকিং, চেক-ইন/চেক-আউট, হাউসকিপিং, লন্ড্রি, রেস্টুরেন্ট/কিচেন, ক্রয়, বিক্রয়, বকেয়া, ক্যাশ ও রিপোর্ট একই লগইন দিয়ে চলে।
