# মুদি ও গ্রোসারি

আপনশপের লাইভ সাইটের ওপর এই প্রজেক্ট বসাবেন না। নতুন ফোল্ডার বা নতুন সাবডোমেইনে দিন। টেবিলের নাম `groc_` দিয়ে শুরু।

## চালানো

1. জিপ খুললে `Grocery_Mudi_Management_System` ফোল্ডার পাবেন।
2. হোস্টিংয়ে নতুন ডাটাবেজ বানান। আপনশপের ডাটাবেজ ব্যবহার করবেন না।
3. `.env.example` কপি করে `.env` করুন এবং ডাটাবেজের তথ্য দিন।
4. সাইট খুলে ইনস্টল করুন। অ্যাডমিন পাসওয়ার্ড অন্তত ৮ অক্ষর। ইউজারনেম `admin`।
5. সেটিংস থেকে পাসওয়ার্ড বদলান।

পণ্য, ব্যাচ/মেয়াদ, ক্রয়, পস বিক্রয়, রিটার্ন, স্টক ট্রান্সফার, বকেয়া, ক্যাশ, বেতন, কমিশন, বারকোড ও রিপোর্ট আছে। ভাষা উপরে **English** / **বাংলা**।
