## ক্রেতার ইনস্টল (Hostinger)

1. Hostinger-এ খালি MySQL ডাটাবেজ তৈরি করুন।
2. `Aponshop_10.98.747_CLEAN_INSTALL.zip` আনজিপ করে `public_html/`-এ তুলুন। ভেতরে আরেকটা `public_html` ফোল্ডার থাকবে না।
3. `public_html/.env` খুলে শুধু এগুলো বদলান:
   - `APP_URL` / `LIVE_DOMAIN` = আপনার ডোমেন
   - `DB_NAME` = ডাটাবেজের নাম
   - `DB_USER` / `DB_PASS` = ডাটাবেজ ইউজার ও পাসওয়ার্ড
4. ব্রাউজারে ডোমেন খুলুন। `.env` ঠিক থাকলে টেবিল অটো বসে। না থাকলে `/install.php` খুলুন।
5. লগইন: **admin** / **Apon7k#4821** — বিস্তারিত `CREDENTIALS.txt` ও `INSTALL-BN.txt`।

লাইভ `.env`, আপলোড ছবি, স্টক/কাস্টমার ডাটা এই জিপে নেই। পুরোনো হিসাব মুছে যায় না।

10.98.503-এর customer-ledger lookup এখন পুরোনো বা অসম্পূর্ণ live database schema-তেও fail-safe। টেবিল/কলাম বা query সমস্যা হলে ক্রয়/মেমো পেজ আর হেডারের পর সাদা হয়ে থামবে না; আগের সংরক্ষিত memo balance ব্যবহার করে পেজ চালু থাকবে এবং সমস্যাটি server log-এ ধরা থাকবে।

কাস্টমার থেকে ক্রয়ে সাবেক পাওনা এখন customer ledger থেকে নির্ভরযোগ্যভাবে আসে এবং এডিট/প্রিন্টে আর supplier running balance দিয়ে শূন্য হয় না। হিসাব সব জায়গায় একই: `সাবেক পাওনা − এই ক্রয় + পরিশোধ = বর্তমান পাওনা`; যেমন `৳৪,৩২৪ − ৳৩,২৬৫ + ৳০ = ৳১,০৫৯`। পুরনো ভুল balance stamp থাকা মেমো খুললেও ledger থেকে সঠিক সাবেক নিয়ে stamp মেরামত হয়।

APONSHOP is a PHP + MySQL/MariaDB point-of-sale and business management app
(sales, purchases, inventory, customers, suppliers, accounts, HRM, loans,
workshop, rentals, reports). Production runs on Hostinger under `public_html`;
see `INSTALLATION.txt` for live deployment rules.

## Run locally

Requirements: PHP 8.1+ (8.3 recommended) with `mysqli`, `mbstring`, `curl`,
`openssl`, `fileinfo`, and MariaDB or MySQL.

```bash
# 1. Database (empty schema with a seeded admin user)
sudo mariadb -e "CREATE DATABASE aponshop CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
  CREATE USER 'aponshop'@'127.0.0.1' IDENTIFIED BY 'aponshop_local';
  GRANT ALL ON aponshop.* TO 'aponshop'@'127.0.0.1';"
mariadb -h127.0.0.1 -uaponshop -paponshop_local aponshop < sql/aponshop_empty_tables.sql

# 2. Local env file (gitignored)
printf 'DB_HOST=127.0.0.1\nDB_NAME=aponshop\nDB_USER=aponshop\nDB_PASS=aponshop_local\nAPP_ENV=development\n' > .env

# 3. Dev server (server.php mirrors the .htaccess rules)
php -S 127.0.0.1:47321 -t . server.php
```

Open http://127.0.0.1:47321 and sign in with `admin` / `Apon7k#4821`.
The app asks for a new password on first login.

Alternatively, skip steps 1–2 after creating an empty database and open
`/install.php`, which writes `.env` and imports the schema for you.

## Not in git

Runtime data stays out of the repository (see `.gitignore`): `.env`,
database dumps under `data/`, user uploads, logs, and release zips under
`downloads/`.
